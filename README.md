# 风过云冈 | Yungang: Where the Wind Remains

> 石上有声，风中留痕。

《风过云冈》是一款以云冈石窟第十二窟（音乐窟）为文化背景的 2D 互动叙事短游戏。玩家化身一阵风，在两位石匠围绕乐器雕刻样式的讨论中，通过触碰乐器、聆听和引导声音推动叙事，感受不同地域音乐与艺术文化的交流。

## 游玩方式

打开部署后的网页，在标题画面点击进入；根据提示点击或触碰交互对象、继续对白。建议开启声音。

## 本地运行

无需安装前端依赖。在项目目录执行：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000/`。

## 项目文件

- `index.html`：游戏网页入口
- `style.css`：布局与动画
- `game.js`：剧情状态、场景调度及交互
- `assets/`：角色、场景、道具、UI 图像
- `audio/`：游戏音效及配乐

上传完整源码和资源后，可在 Settings → Pages 部署静态网页（main 分支，根目录）。
