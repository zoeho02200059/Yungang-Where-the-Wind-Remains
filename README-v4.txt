《风过云冈》最新脚本整合版 v4

直接覆盖项目根目录中的：
- index.html
- style.css
- game.js

assets/ 与 audio/ 不需要改动。

本版已整合：
1. 标题后“你是一阵风”的开场旁白。
2. 最新扩充版甲乙对白，加入代北、凉州、龟兹/西域、鲜卑、中原等戏剧化来源。
3. “旧样 / 新样”区别：旧样沿用旧窟固定构图与持奏方式；新样按眼前真实乐班观察雕刻。
4. 第一轮琵琶、觱篥分别试听后都有对白反馈；第二轮由风把两种声音送到一起。
5. 台词“石头一留下，就永远在这了”改为：“这一刀落下去，往后的人见到的，就是这个样子。”
6. 一年 / 十年 / 百年 / 很久很久 / 风还在吹，改为无框环境文字，不再使用提示框。
7. 开头争执时石匠乙进一步左移；远景乙也略向甲靠近。
8. 结尾加入现代游学团字幕对话，不需要新增人物立绘。
9. 最后以“你轻轻掠过他们的发梢。然后继续向前。”进入知识卡。

推荐继续使用 VS Code Live Server 运行。
